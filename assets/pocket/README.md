# Pocket-dimension textures

`carpet.png`, `wallpaper.png` and `fluorescent.png` are the unmodified diffuse textures from [Backrooms Textures by Amini Allight](https://github.com/amini-allight/backrooms-textures/tree/f7e7cb9a2b40e0e74af559c3acb2a88550b1266d), at commit `f7e7cb9a2b40e0e74af559c3acb2a88550b1266d`.

Their original filenames are `backrooms-carpet-diffuse.png`, `backrooms-wall-diffuse.png` and `backrooms-ceiling-light-diffuse.png`. The carpet source is credited to Seamless Pixels in the upstream readme.

The textures are dedicated to the public domain under CC0 1.0. The full dedication is in [Backrooms-CC0.txt](../../licenses/Backrooms-CC0.txt), also included in release packages.
