# v0.6.0 scoped review

Private credential packages use independent random 192-bit passwords kept in owner-readable local files outside the distributed archives. An 84-byte envelope contains a format marker, random 128-bit salt, random 96-bit nonce and authenticated ciphertext. PBKDF2-HMAC-SHA256 derives an AES-256-GCM key using 600,000 iterations. The marker and pinned identity public key are authenticated as associated data; decrypted seeds must produce that public key. Passwords, derived key buffers and temporary seed buffers use zeroization. This protects the new binary at rest against use without its separately stored password; it is not executable attestation or protection against compromise of an unlocked process. Existing raw key files and older unprotected copies retain authority until revocation/key rotation.

The unlock gate runs before theme selection, App creation, simulation, connection, mods and microphone initialization. Direct-launch and smoke options cannot bypass it. Private editions ignore raw sidecars and profile credentials until their own envelope has unlocked. The native UI does password derivation off the render thread, bounds input and spaces retries. Closing exits without starting the application. All existing signed server challenges, host policy, sequence checks and audits remain authoritative.

One persistent clipboard connection runs on a bounded worker queue with bounded returned text and UI request deadlines. A blocked clipboard provider cannot block rendering. Only successful copy writes confirm party sharing or remove cut text. Pending paste/cut work is discarded on loss of focus or intervening editing. Clipboard contents and passwords are never logged. Linux interoperability checks use independent processes and explicit TARGETS discovery, not only a clipboard service reading its own buffer. Native Wayland requires compositor support or XWayland.

New mode state remains server-owned. Infection cannot replenish survivors through party bot balancing or late joins, and loss of an infected participant cannot freeze the round. Hill scoring requires occupancy and stops on contests. Timer bounds remain mode-specific; the longer Infection clock does not widen other modes’ limits. Lethal tanks cannot regenerate or fire before death resolution. Protocol 18 prevents mismatched mode decoding by older peers.

Verification covers password/identity/tamper rejection, fresh envelope randomness, native clipboard format discovery and Unicode exchange, both new modes and AI goals, real party admission/conversion, all-map hill clearance, and existing authority/security regressions. Cross-platform builds and installed-package checks run in the tagged workflow. This review does not claim to eliminate every possible exploit.
