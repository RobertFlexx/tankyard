Captured drone swarms, proximity voice, and spectating.

- Parried drones and minions merge into one large drone. Hold left click to steer it; release to chase the attacker, including with auto-fire enabled. Right click recalls it.
- Each parry upgrade captures a stronger swarm. Reprisal also heals 15% on success and reduces its cooldown to 3.8 seconds. Bots can parry drones.
- Proximity voice fades with distance. Microphones start muted; press M or click the bottom-right microphone icon to toggle. Settings → Audio controls master and voice playback volume. Server mutes apply to voice.
- Dead players can cycle spectator targets with Left/Right or Previous/Next. Team modes restrict targets to teammates, and server snapshots follow the watched location. Respawning restores your own view.
- Recent chat remains readable outside the chatbox and moves beside upgrade or Sandbox panels. Slash also opens chat while spectating.
- Includes licensed Lucide microphone icons, macOS microphone usage metadata, and release CI checks preserving the compatible Linux ABI. Linux clients now use the system's ALSA runtime.

Linux validation includes 309 Rust tests, eight installer tests, Clippy, content/mod validation, compatible release builds, ABI checks, and native GUI checks at 800×600, 1280×800, and 1920×1080. Voice was checked with virtual audio devices; real-headset conversations remain a manual check.

Update and restart servers as well as clients. This release uses protocol 12.
