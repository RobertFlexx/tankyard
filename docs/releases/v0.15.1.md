# Tank Yard v0.15.1

Arena Workshop gains Luau plugins, resizable panels, more map logic and an updated tutorial. Voice and snapshot delivery get several fixes.

## Arena Workshop

- Drag the inspector and dock edges to resize them, double-click to reset, or press **\\** to hide the panels. The workshop remembers its layout and view preferences.
- Resize a whole selection with its handles. Hold Shift to keep proportions or Alt to resize around the center. Thin selections keep enough space to drag them. Frame the selection with Shift+F, mirror a copy with M, repeat a move with Ctrl+D, and lock groups while editing around them.
- Enabled, reviewed packs can add Luau tools and map checks in the **Tools** tab. Each tool edits a copy of the map, validates its result and applies it as one undo step. Ctrl+R repeats the last tool. Workshop Toolkit provides repeat, ring, frame, snap and mirror tools. Logic Kit builds switch doors, countdowns and sequences.
- The Check tab includes plugin advice and object budgets. The toolkit's gap check handles touching walls and dense maps.

## Map logic and scripting

- Add While inside, On empty and On destroy triggers. Actions can set counters, choose a random signal, repair or damage tanks, and award points.
- Gate triggers on counter comparisons or group visibility. Calculate supports arithmetic, counter operands, random values and a 0/1 flip. Use **Fire** to test an action directly in the editor preview.
- Script actions raise the Luau `map_event` event. Scripts can read map counters and group visibility, send map signals, change counters, and show or hide groups. Script requests apply on the next simulation tick.
- Malformed counter and random-signal settings are rejected safely, including extreme integer values.

## Voice, networking and bosses

- Voice uses a 48 kbps Opus target, a microphone high-pass filter, a speech lead-in and hangover, adaptive playback buffering, fades and a soft limiter for mixed voices. The server reuses listener calculations across each received batch.
- Late snapshots preserve the newest cached wall geometry. Changed walls repeat in four snapshots, with periodic recovery resends, reducing traffic from maps with moving gates.
- Bastion gains a fortress hull, corner towers and a rotating central gun. Sentinel, Skirmisher and Trapper receive restrained armor details.

Protocol **25**, as in v0.15.0. The server sends clients map geometry with server-side triggers removed, so v0.15.0 players can join a v0.15.1 server using the new logic. Maps and editor plugins using the new APIs require v0.15.1 on the machine running them.
