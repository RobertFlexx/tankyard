Spawn protection now pulses white and disappears immediately when you move or attack. Reduced motion uses a steady tint.

- Online arenas replace bots as players join: five bots with one player, one with five, none with six or more. Empty arenas pause until someone joins. Co-op wave enemies stay separate.
- Bots learn visible movement with a small neural predictor. Advanced and Expert have more aim error and slower dodging. Combat stats are unchanged.
- Achievements default to Per match, with Global and Off available on the Achievements page.
- Delayed input bursts no longer kick players. Short fire and ability taps survive packet bunching. WebSocket queues stay bounded, and Reconnect retries the same server.
- The installer includes native app icons on Linux, macOS, and Windows. Linux launchers now match the game window; macOS bundles and Windows shortcuts include their icons.
- Fixed the Windows installer treating a one-item binary list as a string. Windows installation, reinstallation, server installation and checksum rejection are tested before publication.

Play joins tankyard.kokonico.me; Play offline is beside it. Random Events, Co-op PvE, Riposte, and Sandbox level shortcuts are included.

Install or update on Linux and macOS:

```sh
curl -fsSL https://github.com/RobertFlexx/tankyard/releases/latest/download/install.sh | sh
```

Windows packages and PowerShell instructions are in [the installation guide](https://github.com/RobertFlexx/tankyard/blob/main/docs/installing.md). Update and restart the server and relay to apply the online changes. Protocol 9 is unchanged.
