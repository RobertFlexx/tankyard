# Tank Yard v0.13.0

NVIDIA DLSS on GeForce RTX, a new opening that hands straight over to the menu, staff tools as private packs that survive updates, and a complete modding guide. Everything in [v0.12.0](v0.12.0.md) is included.

## Graphics

- **NVIDIA DLSS** on GeForce RTX GPUs, on Windows and Linux. DLSS Super Resolution rebuilds the arena from fewer pixels using its motion, and at 100% render scale it runs as DLAA, the sharpest anti-aliasing the game has. The render scale picks the mode (Performance, Balanced, Quality or DLAA). The DLSS runtime is a separate download the first time you choose it, checked against its SHA-256 before use. On RTX GPUs the Quality and Ultra presets use DLSS. Where DLSS can't run (an older GPU, an old driver), the Graphics tab says why and FSR 1 stands in.
- Laptops with two GPUs draw on the faster one: through the drivers' high-performance request on Windows, and through PRIME render offload on Linux when the NVIDIA GPU isn't driving the display. NVIDIA's Linux driver queues one frame ahead instead of up to three, for lower input latency. If a launch with these changes never opens a window, the next one starts without them, as does `--safe-graphics`.
- The Graphics tab names the GPU with its memory and driver, and warns in red when the system is rendering in software, which usually means the GPU driver is missing. On a Mac, it names the GPU Metal renders on.
- **Adaptive VSync** (Display tab, on by default with VSync, not on macOS): a frame that misses the display's refresh is shown at once instead of waiting a whole refresh, avoiding a stutter at the cost of a brief tear.

## Opening

- A two-second splash in the game's own style: the tank shoots three shapes and the name springs out of the bursts. The menu's live arena comes up behind it, and the menu takes over on the same arena without a cut, as does the staff password prompt.
- It notes what the game runs on, such as "Running on NVIDIA GeForce RTX 4070 with NVIDIA DLSS" or "Running on Apple M2 Pro with Metal and MetalFX", with the trademark notices NVIDIA and Apple ask for. No logos are shown.
- Any key or click skips it. Modifier keys and shortcuts don't, so Cmd+Tab or taking a screenshot leaves it playing, and the key or click that skipped it never reaches the menu.
- With reduced motion, set in the game or in macOS or Windows, it fades without moving. On a Mac set to full screen, it waits for the window to finish moving into full screen before it plays.

## Staff tools

- Creator and central-owner tools now come as private **staff credential packs** published by Tankyard Moderation, in place of separately compiled editions. They're ordinary packs that every public build reads, so they keep working across updates without a private rebuild.
- Before anyone types a password, the game checks the pack's signature against the key built into every client, and refuses a pack that was changed or signed by anyone else. The password is asked for at every launch, and each wrong one doubles the wait before the next try. See [Staff credential packs](../creator-administration.md#staff-credential-packs).

## Mods

- The [modding guide](../modding.md) is rewritten in full: Luau (recommended) and legacy LuaJIT scripting with a migration guide, every event, query and command in the scripting API, HUD widgets, data packs, content, tools and troubleshooting.

Protocol **23**, as in v0.12: v0.13 and v0.12 clients and servers play together, and servers still welcome v0.10 and v0.11 clients.
