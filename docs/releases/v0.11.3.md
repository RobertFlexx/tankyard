# Tank Yard v0.11.3

A tidier Graphics tab and documentation. Everything in [v0.11.1](v0.11.1.md) is included.

- The Graphics tab no longer lists upscalers the game doesn't offer. The space below the toggles now only shows a warning if post-processing can't run on your graphics device.
- The texture filtering note explains what the setting does: it sharpens textured tanks from mods.
- Old internal check logs were removed from the documentation.
- The install scripts accept an optional `TANKYARD_GITHUB_TOKEN` for their GitHub API fallback, which raises GitHub's rate limit on shared networks.

Protocol **22**, unchanged: v0.10.x and v0.11.x clients and servers play together.
