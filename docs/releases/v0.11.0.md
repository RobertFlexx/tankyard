# Tank Yard v0.11.0

Mods can restyle the whole game, the Mods page is easier to use, and the installers cope with a busy GitHub.

## Mods

- **Packs can restyle the game.** Besides tanks, maps, rules and behavior, a pack can now change the main menu (title, subtitle, splash text, the tank on show and a tiled background), recolor the interface (accent, background, panels, lines, text and highlights) and reword any interface text. Like a resource pack, this applies only on your computer and is never sent to servers or other players. See [Modding](../modding.md#menu-theme-and-wording).
- **Browse for a pack…** opens your system's file chooser: Finder, the Windows file dialog, or zenity or kdialog on Linux. Pick a `.zip`, or the `mod.json` inside a pack folder. Pasted folder paths now work too.
- Packs that pass the safety review are enabled as soon as you add them.
- **Open mods folder** shows the library in Finder or Explorer. **Remove** deletes a pack you added.
- **Enabled packs stay enabled.** They are remembered by ID instead of by path, so they survive restarts, updates and starting the game from another folder. Saved paths from older versions are converted automatically. `--mod` on the command line applies to that run only and no longer replaces your saved list.
- A pack in your library replaces a bundled pack with the same ID.

## Faster mods

- Scripts that read the tank list run faster: Gravity Wells takes 42% less time per tick with 40 bots.
- Events no pack listens for are no longer prepared at all.
- The Mods page, offline games and hosting reuse packs that haven't changed instead of reading, scanning and loading them again.
- `tankyard-tools mod-bench --mod <pack>` measures what packs cost per tick in a bot match.

## Installers

- `install.sh`, `install-macos.sh` and `install.ps1` retry GitHub's busy-server answers (502, 503, 504, 429 and dropped connections) with growing pauses, resume interrupted downloads, and stop at once when a release doesn't exist. `TANKYARD_DOWNLOAD_ATTEMPTS` sets the number of tries (6 by default).
- Installing the latest version takes one request fewer, and on Windows no longer uses the rate-limited GitHub API.
- Slow connections are no longer cut off after a fixed time; only stalled downloads are abandoned.
- Windows unpacks the download much faster and waits a moment for a game that is still closing.
- The macOS script reuses a package already in Downloads when its checksum matches.

Protocol **22**, unchanged: v0.10.x and v0.11.0 clients and servers play together.
