# Tank Yard v2.1.4

A small visual patch. Everything in [v2.1.3](https://github.com/RobertFlexx/tankyard/blob/v2.1.4/docs/releases/v2.1.3.md) is included.

## Fix

- The Bastion mark in **Credits** now scrolls with its two credit lines. The mark was receiving the menu's scroll offset twice, so it drifted upward faster than the text as the page scrolled. It is now passed in page coordinates like the labels, which apply the offset once when drawing.

## Compatibility

Multiplayer still uses **protocol 35**. Tank Yard 2.1.4, 2.1.3, 2.1.2, 2.1.1 and 2.1.0 clients and servers can play together; hosts and players on 2.0 builds still need to update together.

See [hosting](https://github.com/RobertFlexx/tankyard/blob/v2.1.4/docs/hosting.md), [bosses](https://github.com/RobertFlexx/tankyard/blob/v2.1.4/docs/bosses-and-learning.md) and [modding](https://github.com/RobertFlexx/tankyard/blob/v2.1.4/docs/modding.md).
