# Tank Yard v0.10.0

Live server status, one-click community servers, FSR 1 upscaling, a new Mods page, art from almost any tool, and a macOS installer.

- **Main server lobbies**: click the main server card on the title screen to open a small, scrolling list of its lobbies, each with its mode, map and a player bar. Pick one to join it. The card shows players online and a live connection bar with measured round-trip time. The list opens inline, so it never covers the buttons below it, and animates smoothly (instantly with reduced motion).
- **Live status everywhere**: saved and recent servers show their name, players, a lock for passwords, mods, and connection bars. Status queries are tiny, rate-limited, can't be used for amplification, and work through the WebSocket relay as well as direct UDP.
- **Community servers in one click**: **Host server → Community server** starts a dedicated server in its own process with your name, port, player limit, lobby size, bots, password, mode and mods. It shows live status, the address to share and the server console, and stops cleanly with the game. **Copy command for an always-on machine** gives the exact command for a spare PC or VPS. New `--port` and `--arena-capacity` server flags.
- **Graphics**: a new Graphics settings tab with quality presets, a 50–200% render scale, AMD FSR 1 upscaling with contrast-adaptive sharpening, FXAA, MSAA, shape quality and texture filtering. Only the arena is scaled, so menus and the HUD stay sharp. Lower scales run faster on weak GPUs; higher scales supersample for the smoothest edges. DLSS, XeSS and HDR need DirectX 12/Vulkan or display paths OpenGL doesn't offer, so they aren't included.
- **Settings**: Display holds window, resolution and frame-limit options; rendering moved to Graphics; button rows are aligned and evenly sized.
- **Mods page**: a library with icons, versions, creators and on/off switches, plus a detail pane with the description, license, tags, contents, size, safety status, and Source, Download and Issues buttons. Packs describe themselves in a new `tankyard.toml`.
- **Art from almost any tool**: textures and icons load from PNG, JPEG, GIF, BMP, TGA, WebP, ICO, ICNS, SVG, Aseprite, Photoshop and Krita files. 3D models (glTF/GLB, OBJ with materials, STL, PLY) render top-down into outlined sprites in the game's style. Large art is shrunk to fit instead of rejected, and the safety review checks every format's signature.
- **macOS installer**: a standard `.pkg` that installs Tank Yard.app (with the server, bundled mods and docs inside it) into Applications. The install script still works.

Protocol **22**: update clients, servers and relays together. The central server must be upgraded for the lobby list; publishing does not deploy it. See [hosting](https://github.com/RobertFlexx/tankyard/blob/v0.10.0/docs/hosting.md), [modding](https://github.com/RobertFlexx/tankyard/blob/v0.10.0/docs/modding.md) and [Pi upgrade steps](https://github.com/RobertFlexx/tankyard/blob/v0.10.0/docs/central-pi-upgrade.md).
