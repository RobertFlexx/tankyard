# Tank Yard v0.9.0

Lua mods, guarded bases, eight new tanks and a central server that splits into arenas of twenty.

- **Lua script packs** on LuaJIT (built from vendored sources, linked statically on every platform). Scripts react to kills, deaths, damage, spawns, shots, level-ups, captures, rounds and timers; read tanks, shapes, projectiles, bosses, walls, objectives and the arena; and change health, armor, shields, scales, levels, stats, classes, teams, velocity, scores, shapes, bosses and match flow. Packs can also define tanks, maps, rules, textures and mode names from Lua and extend the existing tree. See `mods/bounty_hunt`, `mods/gravity_wells` and `mods/sprinkler`.
- **A sandbox built to hold**: one isolated state per pack per round; no `os`, `io`, `debug`, `ffi`, `jit`, `package`, file loaders or bytecode; the trace compiler stays off so instruction budgets always preempt, including inside coroutines and protected calls; memory, string, pattern and sort limits bound single library calls; every request is validated, and a pack with an invalid request is disabled without partial effects.
- **Packs import as `.zip`** from the Mods page (paste a path or drop the file on the window). Archives are checked for traversal, links, encryption, misreported sizes and compression bombs. Each pack is reviewed before it can run: system commands, file access, native code (FFI declarations, `package.loadlib`), executables for Windows, macOS and Linux, embedded bytecode, encoded payloads and platform shell, PowerShell, AppleScript and persistence commands are reported with file and line. Lua is tokenized properly, so comments, text, table keys, fields and locals that share a library name are not flagged. Flagged packs need explicit confirmation bound to their exact contents. `tankyard-tools scan-mod` runs the same review.
- **Base guardians** for Two Teams, Four Teams, Domination, Tag, Team Deathmatch and King of the Hill: drones patrol each base, attack opponents that come within the marked line, shred incoming bullets, ignore shapes, resist parry capture and respawn one at a time. Tanks whose center is inside their own base take no damage. Bots keep clear of guarded zones. Capture the Core and Mothership keep raidable objectives without guardians.
- **Arenas of twenty** on the central server, on one port and relay. Players join the fullest arena with room, arenas open and close with demand, quiet arenas merge at new rounds without splitting groups, and IDs stay unique for moderation. `arena_capacity` makes this available to any community server.
- **Eight tanks**: Capacitor, Overcharger and Railstorm charge their shots; Caromer, Billiard and Pinball bounce rounds off cover; Bulldozer repairs itself and pulls shapes; Shepherd raises drones from its flanks and heals.
- **Faster simulation**: an indexed wall grid makes the Maze arena about 3.5 times faster per tick with identical results, and large bosses no longer inflate every projectile's collision search.
- **Leaner snapshots**: unchanged walls are no longer resent (clients keep and refresh them), projectile hit histories stay on the server, and distant opponents are sent without aim, cursor, motion or weapon timers.
- **Bastion**: a single malformed packet or invalid request is refused instead of disconnecting the player, a congested client misses cosmetic notices instead of the match, and chat with pasted tabs or line breaks is cleaned rather than refused. Only sustained garbage closes a connection. Distant-opponent concealment defeats radar and aim overlays.
- **Interface**: the main menu shows the Bastion mark and motto; the party panel shows the host, link type, open seats with an Invite action, roles and classes, and separated chat names; the tank tree groups branches under their parents, labels tiers, highlights a tank's lineage and links its upgrades; the death screen names what destroyed you; maps gain palette-tinted floors, cover shadows and an edge band.
- **Fixes**: clicking the party button no longer also clicks the upgrade or menu control beneath it; the review sheet and other overlays block the page under them; the Mods page uses your data folder instead of the working directory and scrolls; low-contrast amber text is legible on light themes; and the tree hint no longer collides with Back.

Protocol **21**: update clients, regular servers and relays together. The central Pi must be upgraded to use arenas and guardians; publishing does not deploy it. See [Pi upgrade steps](https://github.com/RobertFlexx/tankyard/blob/v0.9.0/docs/central-pi-upgrade.md), [modding](https://github.com/RobertFlexx/tankyard/blob/v0.9.0/docs/modding.md) and [hosting](https://github.com/RobertFlexx/tankyard/blob/v0.9.0/docs/hosting.md).
