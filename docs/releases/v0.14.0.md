# Tank Yard v0.14.0

Build custom arenas in the Arena Workshop, host a community on your own domain, and take on three new bosses.

## Arena Workshop

- Open **Map editor** on the main menu. Build solid cover, pads, spawns, objectives and decorations on a grid. Select, resize, rotate, duplicate, mirror and group objects. Undo and redo keep the last 32 operations.
- Add timed gates, entry triggers, announcements and boss arrivals. Speed, mud, repair, hazard and shelter pads affect the match. Preview and tune particle emitters in the FX tab.
- Playtest with F5 and return with Escape. Save a project, import an existing map pack or copy a built-in arena. Export a ZIP to share or load on a server. The included Switchyard example demonstrates a timed gate and linked effects.

[Workshop guide](../map-editor.md) · [Map schema](../modding.md#maps)

## Community hosting and parties

- Run UDP and WebSocket joins from the same dedicated server. The Host page can turn on a loopback domain listener. Copying the host command keeps the enabled packs and starts in the server's data folder.
- Set up DNS and HTTPS with the [domain hosting guide](../hosting-domain.md). It covers Caddy, a tunnel and direct UDP.
- Use **Server → Rules** to adjust combat, movement and progression during a match. Changes preserve health percentages and apply to all arenas. Save the profile from the process console to keep it across restarts.
- Occupied arenas can step concurrently on multicore hosts. Party rosters show ready markers and a shared count that resets each round.

## Combat and polish

- Bosses use distinct, clean hulls and readable cannon mounts. Special attacks lock their aim during the warning. Siege Engine, Skirmisher and Trapper each have their own weapons, movement and offline practice encounter.
- Credits scroll to the final line, including on smaller windows. Large custom maps bound particle and pad detail, and cache block style lookups.

**Multiplayer update:** This release uses protocol **24**. Upgrade the server and clients together. Versions 0.13 and earlier use an incompatible snapshot format.
