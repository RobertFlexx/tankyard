Play now connects to the main server at **tankyard.kokonico.me**. Offline play is beside it, and custom servers are still available through Join server.

This release includes Random Events, ten-wave Co-op PvE, Riposte's homing parry, 15-second spawn protection, Sandbox level shortcuts, HUD fixes, and server replication improvements. Short fire and ability taps now register between simulation ticks.

Precompiled downloads are available for Linux x86-64, Linux ARM64, macOS Intel/Apple Silicon, and Windows x86-64. Linux builds target glibc 2.31. Built-in game assets are included in the executable.

Install or update on Linux and macOS:

~~~sh
curl -fsSL https://github.com/RobertFlexx/tankyard/releases/latest/download/install.sh | sh
~~~

Windows PowerShell:

~~~powershell
irm https://github.com/RobertFlexx/tankyard/releases/latest/download/install.ps1 | iex
~~~

The installers verify downloads against SHA256SUMS. ZIP and tar.gz archives also work without an installer. Each includes the dedicated server and WebSocket relay.

Clients and servers use protocol 9. The central server must run a matching protocol.
