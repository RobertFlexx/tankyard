# Tank Yard v0.11.4

Browse what's inside any mod pack. Everything in [v0.11.3](v0.11.3.md) is included.

## Mods

- **View files** on the Mods page opens a file browser for the selected pack, read straight from its folder or `.zip` without extracting anything. Folders collapse, every file has a type tag, and:
  - Lua, JSON, TOML, Markdown and SVG/XML show with line numbers and syntax colors in a monospaced font, in both the light and dark themes.
  - Art and 3D models show as previews; **Source** switches an SVG to its code.
  - Anything else shows as a hex dump.
  - Arrow keys switch files, and Page Up/Down, Home and End scroll.
- Clicking a finding in **Safety review** opens its file at the flagged line.
- Creators can keep files private with a `[source]` section in `tankyard.toml`: `viewable = false` hides every file's contents, or `private = ["lib/", "*.secret"]` hides just those. Private files are listed with a lock, and the Mods page says the pack has private files. This only affects the browser; the safety review still reads every file. See [Modding](../modding.md).

The game now includes DejaVu Sans Mono for code, under the same license as its existing font.

Protocol **22**, unchanged: v0.10.x and v0.11.x clients and servers play together.
