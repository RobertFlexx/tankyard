# Tank Yard v0.8.1

Fix party guests being disconnected when the relay briefly falls behind.

- Keep party members connected when a bounded relay queue fills. Drop excess UDP datagrams so netcode can recover, instead of treating congestion as a departed guest or terminating the connection. Closed receivers are still removed, and packet, memory and authentication limits stay enforced.
- Send a proper WebSocket closing handshake and a useful reason for actual relay shutdowns. Preserve that reason on the client and log detailed causes on the relay.
- Add regression tests for full queues in both directions, recovery and guest isolation, closing reasons, and eight members playing for 35 real seconds with combat, maximum-size voice frames, heartbeats and a paused guest.

Protocol **20** is unchanged. The queue fix takes effect once the main server's relay runs v0.8.1. The regular server and clients can also be upgraded; updated clients display relay closing reasons.
