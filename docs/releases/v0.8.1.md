# Tank Yard v0.8.1

Party guests stay connected when the relay briefly falls behind.

- A full relay queue drops excess UDP datagrams and lets netcode recover. It no longer treats congestion as a guest leaving or closes the whole connection. Packet, memory and authentication limits still apply.
- A relay shutdown sends a WebSocket closing handshake with a reason the client can display. Detailed causes stay in the relay log.

Protocol **20** is unchanged. The queue fix takes effect once the main server's relay runs v0.8.1. Updated clients display relay closing reasons.
