# Tank Yard v0.10.1

- **Mods on the main menu**: a Mods button now sits beside Tank tree and Settings, so the mod library is one click away (before, it was only reachable from Parties or by dropping a `.zip` on the window).
- **Easier macOS install**: `install-macos.sh` downloads the installer package, verifies it against the release checksums and opens the normal macOS Installer without the Gatekeeper warning. `--file` verifies a package you already downloaded before unblocking it; `--cli` installs from the terminal.

```sh
curl -fsSL https://github.com/RobertFlexx/tankyard/releases/latest/download/install-macos.sh | sh
```

Protocol **22**, unchanged from v0.10.0: v0.10.0 and v0.10.1 clients and servers play together.
