# Tank Yard v0.10.2

Mods page polish.

- Tag pills render cleanly; translucent pills no longer show darker half-circles where their pieces overlapped.
- The Refresh button is no longer clipped at the top of the page.
- The selected mod is outlined instead of filled, so its status stays readable.
- The safety badge is a pill that matches the tags.
- Import only looks active when there is a path to import.
- Packs that still need confirmation show **Review & enable** instead of a primary Enable button.

Protocol **22**, unchanged: v0.10.x clients and servers play together.
