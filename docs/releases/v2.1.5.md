# Tank Yard v2.1.5

Tougher bosses, smoother bosses online, tank settings for the central server's owner, and a Bastion that acts only on proof. Everything in [v2.1.4](https://github.com/RobertFlexx/tankyard/blob/v2.1.5/docs/releases/v2.1.4.md) is included.

## Bosses

- **Trapper** no longer waits in a corner to be worn down. It has 55% more health, moves faster, fights from closer in and throws a tight, fast pair of traps. When it is cornered, it slides out along the walls toward open ground.
- Right after laying its mine pockets, Trapper sends out a spiral: pairs of traps from opposite sides, each pair turned further round and thrown further out. There are eight pairs at first and twelve once it is badly hurt. It holds its other fire until the spiral ends.
- **Guardian, Summoner, Fallen Overlord and Foundry** have more health. Their drones are faster and sturdier, and they head for where you are going rather than where you are. Once hurt, each boss adds a shot to its volleys: Guardian a piercing shard, Summoner twin bullets, Fallen Overlord two seekers and Foundry a heavy shell.
- Online and in parties, bosses no longer stop for a frame each time an update arrives. They move as evenly as they do offline.

## Central server owner

The verified central owner has a **My tank** tab in the server panel. It changes only their own tank: choose any hull by name or ID, then scale weapon damage from 0.25× to 8× and shot speed from 0.25× to 3×. The settings last for the round and mark the arena as modded. If the owner's verification ends, the server removes their shots and returns their original hull. See [server administration](https://github.com/RobertFlexx/tankyard/blob/v2.1.5/docs/creator-administration.md#the-central-owners-tank).

## Bastion Anticheat

- Bastion now acts only on proof: a request the game's own client never sends, whatever the network does to its packets. Each proof counts once, however many later packets repeat the same bad frame, and three distinct proofs within a minute close the connection. One stray request can't end a session.
- Input frames out of order inside one packet are now a proof.
- Staff requests are checked against game data that a patch can change, so one that fails is refused with a message and never counts as a proof.
- Observe mode records proofs and keeps players connected. When enforcing, each distinct proof gets an audit line before the disconnect.
- Tests replay the game's input stream through loss, duplication, delays of up to three seconds and shuffled delivery, and run a real client over a poor emulated connection across round restarts and a sequence wrap. Neither produces a finding.

See [Bastion Anticheat](https://github.com/RobertFlexx/tankyard/blob/v2.1.5/docs/bastion-anticheat.md).

## Compatibility

Multiplayer still uses **protocol 35**. Tank Yard 2.1.5 and 2.1.0–2.1.4 clients and servers can play together; hosts and players on 2.0 builds still need to update together. The boss changes, Bastion and the **My tank** tab run on the server and arrive when a host updates. Smoother bosses online come with the client. The [hosting guide](https://github.com/RobertFlexx/tankyard/blob/v2.1.5/docs/hosting.md#upgrading-to-215) covers upgrading.

See [bosses](https://github.com/RobertFlexx/tankyard/blob/v2.1.5/docs/bosses-and-learning.md) and [hosting](https://github.com/RobertFlexx/tankyard/blob/v2.1.5/docs/hosting.md).
