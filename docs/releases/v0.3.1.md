# Tank Yard v0.3.1

Resolution, monitor, cursor and slider fixes, plus safer public-server relays.

- Fixed resolutions apply immediately and when settings are saved. Fullscreen uses the selected render resolution, while Native uses the monitor's pixels. The interface and pointer stay aligned. Leaving fullscreen restores the window's size and position, including on monitors with negative desktop coordinates.
- Linux uses exact XRandR dimensions and the desktop's themed cursor, respecting its scale and configured size. Windows uses the current window's monitor, and macOS uses native content sizing.
- Stepped sliders use the correct increment. Quick clicks and drags survive frame boundaries and interface-scale changes. Changing settings pages cancels an unfinished drag.
- The regular server's official profile includes signed creator administration. `--central` works with built-in defaults when configuration files are absent. An explicit `creator_admin = false` revokes access. Community hosts must opt in, and password-protected hosts keep the tools disabled.
- Banning one relay client no longer excludes everyone sharing the relay address. Shared-address bans target the connection and verified account. Configured Docker relay addresses are supported, and legacy blanket bans on them are ignored. Persistent bans of individual guests behind a shared relay require verified accounts.
- WebSocket relays bound handshake time, connections, packet rates and idle time in both directions. Oversized datagrams and invalid limits are rejected, stalled connections apply backpressure, and failed workers release their connection slots. A failed extension marks a round modified if it may have changed gameplay.

When updating a server, keep its tunnel, relay routing, configuration, bans and writable audit volume. See [creator administration](../creator-administration.md) and [hosting](../hosting.md).

Protocol **15** is unchanged from v0.3.0. Downloads cover Linux x86-64/ARM64, macOS universal, Windows portable and the Windows installer. The private creator client remains separate in this release.
