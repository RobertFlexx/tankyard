Resolution, monitor, cursor, and slider fixes, plus safer public-server relays.

- Apply fixed window resolutions immediately and on Save settings. In fullscreen, fixed resolutions select the render buffer while Native uses the current display's pixels. Preserve logical UI/input alignment and bound intermediate textures. Keep fullscreen on the window's monitor, including displays with negative desktop coordinates; restore window size and placement afterward and remember placement across launches.
- Use exact XRandR pixels on Linux, the current window's monitor on Windows, and native content sizing on macOS. Enter fullscreen after identifying the game window. Linux uses the desktop's themed, scaled cursor instead of a tiny bitmap cursor, while respecting a configured cursor size.
- Fix stepped sliders missing their step multiplier, quick clicks lost between frames, and dragging interrupted when interface scale changes. Keep pointer capture scoped to its panel and cancel stale capture when changing display/layout pages.
- Include signed creator administration by default in the ordinary server's official public profile. `tankyard-server --central` works without a creator-server binary or an extra creator opt-in, with built-in defaults when configuration files are absent. Explicit `creator_admin = false` revokes the official default; community hosts must opt in. Password-protected/private hosts remain disabled. Preserve signatures, fresh challenges, replay/round/rate checks, request-before-execution auditing, and immediate local revocation. Keep private client source, signing code, and credentials out of public source and assets.
- Prevent one relay client's ban from excluding every player sharing its address. Scope shared-address bans to the connection and verified account; support configured Docker relay addresses and ignore legacy blanket bans on them. Direct address bans remain available. Durable bans of individual guests behind a shared relay require verified accounts.
- Bound complete WebSocket handshakes, connection counts, per-direction packet rates, and both-direction idle time. Detect oversized UDP truncation, preserve backpressure, reject invalid relay limits, sanitize diagnostic forwarding headers, and release connection counts even on worker faults. Trusted extension failures mark potentially changed rounds modified.

The central Raspberry Pi/Docker process still needs an operator update; publishing this release does not replace its running binaries. Preserve its Cloudflare tunnel, relay routing, configuration, bans, and writable audit volume. See [creator administration](../creator-administration.md) and [hosting](../hosting.md).

Protocol 15 is unchanged from v0.3.0. Public packages include Linux x86-64/ARM64, macOS universal, Windows portable, and graphical Windows setup; the creator client stays separate.
