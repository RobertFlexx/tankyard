# Tank Yard v0.3.0

Creator tools now work with the regular server, saved servers are easier to manage, and drone bosses give players more room to recover.

- `tankyard-server` handles creator commands directly. A separate creator-server executable is no longer needed.
- Official and central templates enable creator tools. Existing configurations, community servers and personal hosts stay opted out. Public community hosts can opt in with a server ID and audit path; password-protected hosts keep the tools disabled.
- Staff commands are signed for the server, connection challenge, round, sequence and exact payload. Rate and resource limits still apply. The audit log records requests and outcomes, and the host can revoke access immediately from the console. A badge or ordinary Owner role does not grant creator powers.
- Arena tools announce gameplay changes and disable regular achievements for that round. Kick, ban and mute apply to the current server. Commands cannot run arbitrary code or control another server.
- Favorites and Recent have separate counted, paginated tabs in Join server and Settings → Servers. Sort, reorder, delete or clear entries, and star a recent server to save it. Changes save immediately.
- Summoner's drone range drops from 1,000 to 820 units, with a shorter leash and less damage and replenishment pressure. Other drone bosses respect their owners' range, line of sight and protected players. Bosses pause primary fire during special warnings and recover for 0.4 seconds afterward. Fallen Booster, Prism, Bastion and Tempest attacks are slightly less punishing; boss health and encounter chance are unchanged.
- A central configuration and Raspberry Pi/Docker upgrade guide are included. Operators still need to update the running central process.

Update clients, servers and relays together: protocol **15**. Downloads cover Linux x86-64/ARM64, macOS universal, Windows portable and the Windows installer.
