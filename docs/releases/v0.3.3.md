# Tank Yard v0.3.3

Smoother interface scaling, working texture-filter preferences and a portable private creator client.

- The layout stays steady while dragging Interface scale. The selected percentage is shown during the drag and applied on release. The slider keeps its scroll position, and leaving the page cancels an unfinished change.
- Text widths are cached within a fixed memory budget, visible glyphs are prepared in batches, and clipped labels are skipped. Kerning stays consistent across desktop DPI settings.
- Texture-filter preferences can be selected and saved before loading a texture pack. Anisotropic filtering is detected in legacy and core OpenGL contexts, and changing the filter reuses existing mipmaps. Built-in vector tanks are unaffected.
- Settings and connection errors have their own banner above the footer buttons.
- The private creator executable can be moved or renamed without a neighboring key file. Server authentication, host policy and signed-command checks are unchanged.
- Temporary download failures while building the Windows installer are retried. The installer compiler remains pinned to its checked version.

Protocol **15** is unchanged. Downloads cover Linux x86-64/ARM64, macOS universal, Windows portable and the Windows installer. Creator actions remain subject to Bastion's authorization checks.
