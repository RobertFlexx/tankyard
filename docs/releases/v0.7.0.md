# Tank Yard v0.7.0

Parties now enter the match immediately and stay connected when returning to the main menu.

- Use the leader's actual public IPv4 address in internet invites. Add background address discovery, temporary UPnP UDP forwarding, lease renewal/cleanup, and clear manual-forwarding or LAN setup instructions. Never silently copy a detected LAN address as the default internet invite.
- Add a collapsible tank-icon party roster, current member/leader status, local voice mutes that survive round changes, unread chat counts and party text chat with clipboard paste.
- Keep the hosted server, members and chat alive while browsing menus. Add Resume party / Enter match and explicit confirmation before leaving; protect the party from accidental replacement by another session.
- Move the roster aside while tank upgrades are open. Fit the expanded party panel to the window and keep it clear of the gameplay controls.
- Preserve invite proofs, process-local host authority, server-owned membership, bounded chat/packets and separate creator/central-owner credentials.

Protocol **19**: update clients, regular servers and relays together. Publishing this release does not deploy the central Pi; see `docs/central-pi-upgrade.md` for the operator steps. Internet hosting still depends on the router, firewall and ISP allowing incoming UDP. Private credential editions remain separate local packages.
