# Tank Yard v0.3.2

Accessibility settings now apply throughout the game, with responsive menus and Bastion Anticheat.

- Interface scale resizes widgets from 80% to 140%. Enlarged pages scroll with fixed navigation and matching pointer coordinates, and Sandbox tools fit around the HUD.
- Colorblind mode applies a distinct palette to FFA, all four teams, previews and shared accents. Geometric team markers provide another way to identify teammates. High-contrast labels have solid backgrounds and readable text.
- Reduced motion stops decorative animation, particles, score drift, camera easing, shake and boss-arrival flashes. Combat information stays visible. Effects intensity accepts zero, and Settings includes a live accessibility preview.
- Boss alarms have their own volume control and audio preview. Audio settings explain muted or unavailable devices. Graphics settings disable unsupported filtering and antialiasing choices while retaining supported MSAA in fixed-resolution fullscreen.
- Bastion checks player input against the server's game rules. Diagonal movement is normalized, duplicate or reordered inputs are ignored, and reconnecting after a pause or packet loss does not grant extra simulation time. Ping alone does not trigger suspicion or an automatic cheating ban.
- Creator actions still require the pinned signing key, a fresh connection identity, the current round and sequence, and a signature over the exact command. Forged names and client flags cannot grant access. The Bastion boss model appears in Credits.

Protocol **15** is unchanged. Downloads cover Linux x86-64/ARM64, macOS universal, Windows portable and the Windows installer.
