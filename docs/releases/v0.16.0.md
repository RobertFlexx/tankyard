# Tank Yard v0.16.0

Workshop gates take several conditions, watchers and sequences arrive, navigation suits trackpads, busy servers run lighter, and Tank Yard now runs natively on FreeBSD.

## Map logic

- A trigger can check up to four conditions: a counter, whether a group is shown, how many tanks are inside its area, or the round time. Combine them as All (AND), Any (OR), Not all (NAND), None (NOR) or Just one (XOR).
- A shut gate can send an otherwise signal, which makes it an if/else. New otherwise signals pick a free channel.
- Watchers fire when a counter changes, a group is shown or hidden, or a boss is defeated. Sequence signals the next of a run of channels each time, and Reset triggers lets a group's triggers start afresh.
- Press P for the live Logic tab. It can step, change speed, edit counters, switch groups, send signals and test a boss defeat. Each condition card shows whether it holds and whether the gate is open.
- Logic and Gates are separate palette tabs. Gates holds ready-made AND, OR, XOR and if/else pieces, levers, sequences, watchers and resets. Wires show what each trigger depends on, and labels make room for each other when crowded.
- Scripts can call `reset_map_triggers(group)`, and the bundled Logic Kit adds a Lever bank tool.
- The [logic gates tutorial](https://github.com/RobertFlexx/tankyard/blob/v0.16.0/docs/logic-gates-tutorial.md) builds a two-lever vault step by step, and the [video](https://github.com/RobertFlexx/tankyard/blob/v0.16.0/docs/logic-gates-tutorial.mp4) shows it in under two minutes.

## Workshop navigation

- Pan (4) moves the view with a plain drag. In Pan, arrows and WASD move the view even with objects selected.
- The Scroll setting chooses Auto, Trackpad or Mouse. With a trackpad, two fingers pan, and Ctrl or Cmd with scrolling zooms around the pointer. Pan and zoom speeds go from 0.25× to 3×, and 100% resets the zoom. The workshop remembers these settings.
- Zoom follows how far you scroll instead of jumping a full step for any movement.
- Tab and Shift+Tab cycle through overlapping objects under the pointer. Resize handles and panel dividers are easier to grab.

## Scrolling everywhere

- Menus, chat, the lobby and mod lists, the mod viewer and the tank tree scroll smoothly with trackpads and step evenly with wheels, on macOS, Windows, Wayland and X11. Ordinary wheels no longer scroll slowly on Wayland.

## Servers

- Projectile, wall and navigation checks skip distant objects. In a local test with 64 players and 24 bots on a maze map, 99th-percentile tick time fell from about 3.3 to 1.8 ms.
- Starting a server lists the addresses players join from this computer, the local network and the internet. Every option has clearer help.
- Linux, macOS and FreeBSD archives include `host-server.sh`, which writes a settings file on first run and then starts the server with it. The systemd unit keeps settings, bans and logs in `/var/lib/tankyard`. The [hosting guide](https://github.com/RobertFlexx/tankyard/blob/v0.16.0/docs/hosting.md) walks through installing, configuring, opening the port and running a service.

## FreeBSD

- FreeBSD 15 and newer on amd64 get their own build of the game, server, relay and tools, made on FreeBSD itself. Install the sound plugins with `pkg install alsa-plugins`, then run `fetch -o - https://github.com/RobertFlexx/tankyard/releases/latest/download/install.sh | sh`.
- The game uses X11 and OpenGL with Mesa or NVIDIA's driver. With NVIDIA, it queues one frame ahead, as on Linux. DLSS is available only on Linux and Windows.
- The FreeBSD archive carries an rc.d script that runs the server as its own user, restarts it if it stops, reopens its log when rotated, and can run several named servers.
- The [FreeBSD guide](https://github.com/RobertFlexx/tankyard/blob/v0.16.0/docs/freebsd.md) covers NVIDIA setup, sound, hosting and building from source.

## Fixes

- Leaving a WebSocket server through the relay reaches the server at once on FreeBSD, instead of after a timeout.
- The installer works without curl on FreeBSD, using `fetch` and `sha256`.

Protocol **25**, as in 0.15. Players on any 0.15 or 0.16 build play together. Maps that use the new logic need a 0.16 server, or 0.16 to play them offline; older servers refuse them with a clear message. Maps without it save exactly as before.
