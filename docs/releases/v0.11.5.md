# Tank Yard v0.11.5

Markdown files read like documents in the mod file browser. Everything in [v0.11.4](v0.11.4.md) is included.

- `.md` files in **View files** open rendered: headings, paragraphs, bullet, numbered and task lists, quotes, code blocks, tables, bold text, inline code and links.
- A **Rendered** switch beside the file name shows the Markdown as written, with syntax colors and line numbers. SVG art has the same kind of switch, **Preview**, in place of the old Source button.
- Private files stay private either way.

## Fixes

- Server status probes no longer send a ping twice after its reply comes back, which could count extra replies, show negative packet loss and skew ping and jitter in the server browser.

Protocol **22**, unchanged: v0.10.x and v0.11.x clients and servers play together.
