# Tank Yard v2.1.2

Boss fights now finish cleanly, including a killing blow that empties the health bar in one hit. The bar, off-screen pointers and party labels also handle a minimized window and unusually large bosses.

## Multiplayer

Once a player has joined, Bastion checks each decoded request against the limits of the negotiated protocol. A control request outside those limits, an input value outside its range, or two copies of the same recent frame that disagree are refused. By default the host discards the message and disconnects that player with a reason; `observe` mode discards and logs it while the player stays connected. Loss, reordering, long gaps and sequence wraparound are ordinary, and the client refuses its own contradictory frames before sending. The action applies only to the connection; players can reconnect.

Hosts can set `bastion_mode = "observe"` to discard invalid requests from joined players and review the findings in the moderation log while those players stay connected. Handshake and malformed-traffic rules are unchanged. See the [host settings](https://github.com/RobertFlexx/tankyard/blob/v2.1.2/docs/bastion-anticheat.md#host-settings).

Multiplayer uses **protocol 35**. Players and hosts on 2.1.x can update independently. The [hosting guide](https://github.com/RobertFlexx/tankyard/blob/v2.1.2/docs/hosting.md#upgrading-to-212) covers upgrades from 2.0.x.
