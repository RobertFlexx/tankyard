# Tank Yard v0.15.2

Menus follow your frame limit, frame limits hold their exact rate, and the Arena Workshop tutorial and a full plugin guide now live in the docs.

## Frame rate

- The title screen and menus run at the selected frame limit instead of stopping near 60 fps. With VSync on and no limit, they follow the display's refresh rate. Battery saver still holds games to 60 fps and menus to 30.
- Frame limits now count the time spent presenting each frame and keep a steady schedule, so 60 and 144 fps limits run at 60 and 144 rather than overshooting or falling short. The opening animation uses the same pacing.

## Arena Workshop

- When a plugin tool removes objects and doesn't choose what to select, the selection keeps only objects that still exist.
- The [tutorial video](https://github.com/RobertFlexx/tankyard/blob/v0.15.2/docs/arena-workshop-tutorial.mp4) is in the repository's docs, linked from the README and the [workshop guide](https://github.com/RobertFlexx/tankyard/blob/v0.15.2/docs/map-editor.md). Game packages leave it out to keep downloads small.
- The new [editor plugin guide](https://github.com/RobertFlexx/tankyard/blob/v0.15.2/docs/editor-plugins.md) covers installing plugins, a complete first tool, pack layout, every parameter type, the `ctx` API, coordinates, group and counter allocation, map checks, execution limits, distribution and troubleshooting. A test runs its example exactly as printed.

## Documentation

- Guides, server measurements and earlier release notes are tidied for players, mod authors, hosts and maintainers. The bundled Workshop Toolkit and Logic Kit READMEs link to the plugin guide.

Protocol **25**, as in v0.15.0 and v0.15.1. Clients and servers from those versions play together.
