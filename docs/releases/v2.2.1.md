# Tank Yard v2.2.1

- **Skill tooltips.** F3 network diagnostics sit in the footer, clear of skill descriptions.
- **Boss health bars.** Each active boss has a separate health bar with its own damage trail and targeting pulse. Larger fights use a compact grid.
- **Light arenas.** Lamps, beams, and combat effects keep bright centers and colored halos against pale floors. The map editor preview uses the same lighting.

**Multiplayer.** Version 2.2.1 works with 2.2.0 games, servers, and relays on protocol 36.
