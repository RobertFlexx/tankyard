# Tank Yard v1.5.2

Community servers can now host arenas where moving gates close off whole rooms. Earlier versions could accept the pack in the workshop and content tools, then reject it as “invalid game data” when starting a server.

- The server checks reachability before removing the triggers and paths that only it runs. Players receive the same collision geometry and see the doors open and close through snapshots.
- Joining clients check that geometry without mistaking closed gates for permanent walls. Coordinate, clearance, size and resource-limit checks remain in place.
- Servers still reject genuinely disconnected authored maps. Regression checks cover closed gates, malformed coordinates, oversized catalogs and the player catalog's content hash.

Everything in [v1.5.1](https://github.com/RobertFlexx/tankyard/blob/v1.5.2/docs/releases/v1.5.1.md) is included.

## Compatibility

The wire format remains **protocol 31**. Existing 1.5.x matches stay compatible. For an arena whose gates can close off rooms, update **both the server and visiting clients to 1.5.2**; older versions may reject its map data.
