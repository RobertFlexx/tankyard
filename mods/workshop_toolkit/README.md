# Workshop Toolkit

Example Arena Workshop plugins, written in Luau. The
[editor plugin guide](../../docs/editor-plugins.md) explains the API they use.

Enable the pack on the Mods page, then open the map editor's **Tools** tab:

- **Repeat** copies the selection several times along a step.
- **Ring of blocks** places blocks in a circle around the last place you
  clicked on the canvas.
- **Arena frame** lines the edges with blocks and leaves a doorway on each side.
- **Snap to grid** moves the selection onto the editor grid.
- **Four-way mirror** copies the selection into the other three quarters.

It also adds a **Narrow gaps** note to the Check tab when two always-solid
blocks leave an opening tanks cannot drive through.

The pack only adds editor tools, so enabling it never changes a match.
