# Switchyard

Requires Tank Yard 0.14 or a protocol-24 development build.

A small data-only example of the Arena Workshop schema. Group 1 links the center gate, a speed pad and a particle emitter. The group hides every eight seconds and returns three seconds later. Routes around the gate stay open.

Import the folder on Mods, enable it and choose Switchyard in Offline modes, or start a server with `--mod mods/switchyard --map switchyard`. The workshop can import its `mod.json` to edit it.
